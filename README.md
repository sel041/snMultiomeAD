# snMultiomeAD
Contains the scripts pertaining to Seoyeon Lee, Nathan R. Zemke, et al.; Age-dependent cGAS–STING Activation Impairs Microglial Amyloid Clearance through Suppressing MEF2C

## Data availability
The data generated in this study have been deposited in the NCBI Gene Expression Omnibus (GEO) under accession numbers GSE288295 for the mouse 10x multiome, GSE288063 for the human 10x multiome, and GSE289830 for the ChIP-seq data.
